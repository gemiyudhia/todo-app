# Todo List

Aplikasi todo list sederhana dengan React, TypeScript, dan Tailwind CSS. Data disimpan di localStorage sebagai alternatif karena tidak ada menggunakan database.

## Fitur

- Tambah tugas
- Edit tugas
- Tandai selesai
- Hapus tugas

## Menjalankan

```bash
npm install
npm run dev
```

Buka URL yang tampil di terminal http://localhost:5173
