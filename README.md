# Todo List

Aplikasi todo list dengan React, TypeScript, dan Tailwind CSS. Data disimpan di localStorage sebagai alternatif karena tidak ada menggunakan database.

## Fitur

- Tambah tugas
- Edit tugas
- Tandai selesai
- Hapus tugas

## Pra-syarat

- node.js

## Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/gemiyudhia/todo-app.git
   ```

2. Masuk ke direktori project:

   ```bash
   cd todo-app
   ```

3. Instal dependencies dan jalankan:

```bash
npm install
```

```bash
npm run dev
```

Buka URL yang tampil di terminal http://localhost:5173
